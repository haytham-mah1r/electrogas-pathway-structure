How to read this: the left bar is every tracked session starting at /. Each ribbon flowing right is the next page those sessions landed on, and — for the three busiest sections (multi‑gas detectors, single‑gas detectors, and the About page) — the page after that. Flow width is square‑root scaled so low‑volume paths stay visible next to high‑volume ones; the true session count is always in the label and the hover tooltip.
Links: every page name marked ↗ is a live link, matched against the site's own XML sitemaps — click it to open the real page in a new tab. Two things aren't linked: Others, which rolls up many small long‑tail paths rather than one page, and /current-promotions/, which no longer appears in the current sitemap. The four "multi‑gas‑clip" pages under the Multi‑Gas Detectors branch were shown identically (and truncated) in the original export, so they're matched here to the four real multi‑gas‑clip product pages — the session counts are accurate, the exact page‑to‑count pairing among those four is a best‑effort guess.
